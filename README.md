# 곰줄 영화 분할기

영화를 선택해 250MB 또는 512MB 이하의 분석용 MP4로 자동 분할하는 Windows 앱입니다.

## 프로그램 받기

1. 이 저장소의 **Actions → Build Windows EXE**를 엽니다.
2. 초록색 체크가 표시된 최신 실행을 엽니다.
3. **Artifacts → GomjulSplitter-Windows**를 다운로드합니다.
4. ZIP을 전부 풀고 `GomjulSplitter/GomjulSplitter.exe`를 실행합니다.

Python 설치는 필요하지 않습니다. `_internal`을 포함한 폴더 전체를 보관하세요.
최초 분할 시 FFmpeg를 자동 준비하므로 인터넷이 필요합니다. 영화는 PC에서 처리합니다.

SRT는 선택 사항입니다. 선택했을 때만 원본 자막 사본과 Part별 SRT를 생성합니다.
예상 경계 ±10초에서 화면 전환을 찾고, 기본 설정에서는 전환이 없으면 시간 기준으로 대체합니다.
재인코딩, 용량 검사, 원본 시간표, 중단 후 이어하기를 제공합니다.

Windows 빌드는 분할 엔진 테스트와 실제 EXE의 창 생성·자막 유무 분할 검사를 통과해야 다운로드 파일을 게시합니다.
사용자의 PC에서 직접 확인하는 시각적·재생 품질 검토를 대신하지는 않습니다.
